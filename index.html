Paste a public link to the PDF file. The host has to allow other sites to load it (CORS). GitHub Pages, Netlify, S3 and most CDNs do.

Host the flipbook file yourself

  1. Download the flipbook as a single HTML file.
  2. Upload it to any web host: Netlify Drop, GitHub Pages, Cloudflare Pages or your own site.
  3. Paste its address here.
